# Product

## Register

product

## Users

Financial analysts opening locally generated HTML to review an FS document and
move statement data into Excel. They need to scan dense financial tables and
copy complete spreadsheet context without treating the presentation as the
source of truth.

## Product Purpose

FS is a versioned JSON format and reference CLI for structured financial
statements. The JSON Schema and semantic contract are authoritative. Rendered
HTML is a non-normative convenience view that makes validated documents easier
for people to review and transfer into spreadsheet workflows.

## Brand Personality

Compact, trustworthy, utilitarian.

## Anti-references

Avoid decorative dashboards, marketing-page styling, spreadsheet imitation,
and visual treatment that implies the HTML adds accounting meaning or carries
the authoritative data contract.

## Design Principles

- Keep the FS JSON document visibly and operationally authoritative.
- Optimize dense tables for analyst review and spreadsheet handoff.
- Preserve complete context, including units, when data leaves the view.
- Prefer familiar, semantic web interactions over custom interface behavior.
- Keep every rendered file deterministic, offline, and self-contained.

## Accessibility & Inclusion

Target WCAG 2.2 AA. Use semantic and explicitly named tables, support keyboard
operation and visible focus, preserve meaning without color, and avoid
unnecessary motion.
