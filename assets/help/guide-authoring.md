# fs guide authoring

Show the prerequisites, encoding workflow, and validation loop for an
author-resolved financial model.

## Usage

`fs guide authoring [--log-level <level>]`

Use `--help` or `-h` for this reference. Logging defaults to `none`; levels are
`all`, `trace`, `debug`, `info`, `warn`, `warning`, `error`, `fatal`, and
`none`.

## Examples

```sh
fs guide authoring
fs guide authoring --log-level debug
```
