# fs guide

Read focused standalone FS guidance.

## Usage

`fs guide <topic> [--log-level <level>]`

The required topic is `authoring`. Use `--help` or `-h` for this reference.
Logging defaults to `none`; levels are `all`, `trace`, `debug`, `info`, `warn`,
`warning`, `error`, `fatal`, and `none`.

## Examples

```sh
fs guide authoring
fs guide authoring --log-level none
```
